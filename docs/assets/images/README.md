# Screenshot Images

This directory should contain screenshots for the GitHub Pages demo page.

## Required Images

### 1. TUI Screenshot
- **Filename:** `tui-screenshot.png`
- **Description:** Screenshot of the WiFi Jammer Text User Interface (TUI)
- **Content:** Should show the TUI interface with network scanning results, similar to the image provided in the user's request showing:
  - Dark-themed terminal interface
  - Network table with SSID, BSSID, Channel, RSSI, and Security columns
  - Status message "Scan stopped"
  - Action buttons (Stop Scan, Select & Attack)
  - Footer with keybinds

### 2. GUI Screenshot
- **Filename:** `gui-screenshot.png`
- **Description:** Screenshot of the WiFi Jammer Graphical User Interface (GUI)
- **Content:** Should show the GUI interface with the Network Scanner tab active, similar to the image provided in the user's request showing:
  - macOS-style window with traffic light buttons
  - Tab navigation (Network Scanner, Attack Configuration, Progress Monitor)
  - Interface selection dropdown
  - Scan Networks and Refresh Interfaces buttons
  - Network table with column headers
  - Status bar at bottom

## Adding Images

1. Capture screenshots of the TUI and GUI interfaces
2. Save them as `tui-screenshot.png` and `gui-screenshot.png`
3. Place them in this directory (`docs/assets/images/`)
4. The HTML pages will automatically display them

## Image Specifications

- **Format:** PNG (recommended) or JPG
- **Size:** Optimize for web (recommended max width: 1200px)
- **Quality:** High enough to read text and see interface details clearly
